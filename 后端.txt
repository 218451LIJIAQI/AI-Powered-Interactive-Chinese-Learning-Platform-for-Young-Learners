特殊产品要求
============================================================

本产品是面向年轻学习者的 AI 中文学习平台，因此必须额外严格检查：

1. Student-facing APIs

- 必须安全
- 必须 resilient
- 必须容忍不完美客户端行为
- 不应泄露过多数据
- 不应暴露内部状态
- 不应允许越权访问学习记录、课程、报告、AI 对话或个人信息

2. Teacher APIs

- 必须严格执行教师角色权限
- 必须严格执行 ownership / classroom / course / student boundary
- 不允许教师访问不属于自己的学生、课程、作业、报告或付款数据
- 关键操作必须可审计

3. Admin APIs

- 必须明确 admin 权限边界
- 高风险操作必须有审计轨迹
- 不应把 admin 便利性建立在绕过安全约束上
- 不应过度暴露学生、教师、支付或 AI 敏感数据

4. Demo / mock / fallback / no-op behavior

- 不得误导生产客户端
- 不得让看似真实的操作实际没有执行
- 不得让 mock provider 泄漏到真实业务流
- 不得把 fallback 伪装成成功业务结果

5. AI endpoints

- 不得 unsafe prompt echoing
- 不得过度保留 prompt/response
- 不得泄露学生个人信息
- 必须有适当 moderation / safety / fallback 边界
- provider 错误必须清楚处理，不能误导用户或客户端

6. Commerce endpoints

- 正确性优先于便利性
- 幂等性优先
- payment/refund/payout/callback 必须可追踪
- 第三方 transaction id 必须受约束
- 必须避免重复扣款、重复发货、重复退款、权益错配

7. Audit logs

- 必须支持 accountability
- 不得不必要地保存 secrets、tokens、passwords、reset links、完整敏感 prompt、敏感 response、过量 email/IP 等
- 必须平衡可追踪性和数据最小化

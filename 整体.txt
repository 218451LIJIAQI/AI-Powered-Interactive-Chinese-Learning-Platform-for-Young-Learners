------------------------------------------------------------

- critical security issues
- authorization bypass
- ownership check gaps
- privacy leaks
- payment/idempotency issues
- data integrity issues
- schema drift
- broken API contract
- broken build/typecheck/test
- misleading fake/no-op product behavior
- major UX blockers
- missing validation
- high-risk migration issues
- hot-path performance problems
- critical documentation mismatch

修复原则：

- 能根治就不要绕过
- 能跨层一致解决就不要只改一层
- 能加约束就不要只靠应用代码
- 能提升类型安全就不要留下 any/unknown 漏洞
- 能提升用户体验就不要只让它“不报错”
- 能提升安全默认值就不要依赖人工记忆
- 能补测试就补关键路径测试
- 能修文档就让文档匹配真实运行方式
